# gll-cursor

A cursor that changes shape with what is under it.

| Folder | Package | Technology |
| --- | --- | --- |
| [`angular1/`](angular1) | `@sossiogll/gll-cursor-angular1` | AngularJS 1 |
| [`react/`](react) | `@sossiogll/gll-cursor-react` | React, with a TypeScript core |

Each is versioned and released on its own, by a pipeline: pushing the tag `angular1/vX.Y.Z` or `react/vX.Y.Z` publishes
that folder.
