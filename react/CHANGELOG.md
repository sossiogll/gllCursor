# @sossiogll/gll-cursor-react

## 0.2.1

No change to the package. This release exists so that gllHub reads `.github/showcase.md`, which it takes from the latest
release.

## 0.2.0

Moves as the AngularJS module does. A CSS transition on position, size, radius, border and fill restarts from where the
cursor is at each new target, so it trails the pointer, comes away from a block as if stuck to it, and changes form
gradually around its centre. Both lags default to 200 ms, the value `b5srl.eu` uses.

## 0.1.0

The cursor rewritten in TypeScript for React: `CursorProvider` and `useCursor`, `transform` and `requestAnimationFrame`
instead of `top` and `left`, `data-cursor` attributes instead of the `gllText` and `gllBlock` classes, themes as CSS
variables, off on touch and with reduced motion.
